# verox

My cybersecurity writeups, security research, and thoughts, covering Hack The Box, TryHackMe, web security, binary exploitation, and hands-on learning. Live at **https://abdullah-5j.github.io**.

To generate pages after adding dated Markdown articles to `posts/`, install `requirements.txt` and run `python build.py`. The website itself is plain HTML/CSS/JavaScript and requires no backend or build process on GitHub Pages.
